О приложении

«Учёт покупок» – веб-приложение для учёта покупок и расходов. В нём ведётся список покупок и справочник магазинов, а на форме расчёта считаются расходы за выбранный период.

Роли
РольВозможности
Только чтение (READ_ONLY)просмотр всех покупок и магазинов, расчёт расходов. Выдаётся при регистрации
Пользователь (USER)добавление, изменение и удаление своих записей, видит только свои записи
Администратор (ADMIN)полный доступ ко всем записям, назначение ролей, мониторинг
Технологии

Java 25, Spring Boot 4.1, Spring MVC, Spring Security, Spring Data JPA (Hibernate), H2 Database, Thymeleaf, Bootstrap 5, Lombok, Spring Boot Actuator, Maven.
